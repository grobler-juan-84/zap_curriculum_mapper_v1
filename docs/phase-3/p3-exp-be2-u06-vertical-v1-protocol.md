## 2. Research question

> Using Phase 1 book evidence and Phase 2 interpretation for Big English 1–3, what **Previous → Current → Future** learning connections can be stated for BE2 Unit 6 *My Day* such that a teacher can tell book evidence apart from AI interpretation — without inventing unsupported prerequisites?

Secondary questions:

1. Which Phase 2 LRs for U6 have clear prior / future anchors, and which remain isolated?
2. Where do topic/theme matches still fail as progression signals (carry forward U6 v1 lessons)?
3. What would a later Phase 3 schema need that this sketch deliberately does **not** invent?

---

## 3. Method (controlled, docs-only)

1. Treat Phase 2 U6 LRs as **Current Learning** nodes (interpretation layer).  
2. Attach Previous / Future candidates only with cited Phase 1 entities + evidence tags.  
3. Classify each edge with a provisional label (`extend`, `contrastive_prior`, `partial_prior`, `recycle`, `weak`, `unsupported`).  
4. Mark gaps (`MISSING_EVIDENCE`, `UNCERTAIN`) rather than inventing links.  
5. Reject false friends explicitly.

Evidence tags (same family as Phase 2):  
`BOOK_EVIDENCE` | `AI_INTERPRETATION` | `UNCERTAIN` | `MISSING_EVIDENCE`

Tables: `EXPERIMENT_SKETCH — NOT LOCKED`.

## 5. Evaluation criteria (defined before results)

| ID | Criterion |

| P3-E6 | No Phase 3 schema / pipeline / UI locked or implemented |
