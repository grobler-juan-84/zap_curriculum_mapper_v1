## 1. Rules

1. Pair **logical lesson components**, not matching page counts.  
2. A **2 SB pages → 1 WB page** relationship can be a valid SB→WB companion.  
3. A **1 SB page → 0 WB pages** component (e.g. Values) is an expected **SB-only** route — not a failed or missing pairing.  
4. This table is a **structural inventory and candidate map**, not proof that every row is content-aligned.  
5. Each proposed relationship still needs **source-based verification** before becoming a curated mapping.  
6. No automatic SB→WB pairing rule. Pagination adjacency alone is never acceptance.
