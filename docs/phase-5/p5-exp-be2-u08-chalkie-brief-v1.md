Create a short slide lesson to SUPPORT Big English 2 SB Unit 8 "Wild Animals" (pp. 128–143).
Do NOT replace the textbook. Do NOT invent extra grammar or long animal word lists.
Target: clear models + guided practice + student speaking. Leave space for teacher creativity.
Age-appropriate English only. Pictures for animals and sentence frames. No filler slides.

════════════════════════════════════
A. CURRICULUM FLOOR (REQUIRED)
════════════════════════════════════

Vocabulary (required names):
giraffe, hippo, kangaroo, cheetah, polar bear, zebra, parrot, monkey, peacock, elephant, crocodile, snake

Ability verbs (use book/song verbs; do not invent a big new verb list):
run, jump, swim, fly, climb, eat (and similar verbs already in the unit song/story)

Core grammar / frames (required):
1) Cheetahs can run.
2) Can a kangaroo jump? — Yes, it can. / No, it can't.
3) Can snakes run? — Yes, they can. / No, they can't.
4) Adjective order before a noun: opinion → size/shape → age → color (+ animal)
   Example shape only: a beautiful big young yellow parrot
5) What animal do you like? I like parrots. They're so beautiful.
   (appreciation adjectives from the book: amazing, beautiful, smart, strong)

Also cover when the book does (do not expand into new lessons):
- Habitats: forest, desert, ocean, jungle (match animals to places)
- Values line: Appreciate animals.
- Phonics ou/ow only if the book lesson includes it — keep brief
- Lead-in preference is OK: Do you like …? then move to ability — keep them separate

Must prepare students for textbook activities on ability Q&A, adjective order, and appreciation speaking.

════════════════════════════════════
B. TEACHING PROGRESSION (REQUIRED)
════════════════════════════════════

Follow this order. Prefer student speaking over reading long text.

1) Animals — see / say names (pictures). Few words per slide.
2) Ability statements — model: [Animal] can [verb].
3) Ability questions — singular then plural:
   Can a/an …? → Yes, it can. / No, it can't.
   Can …s …? → Yes, they can. / No, they can't.
4) Guided practice with pictures → then less support → pair ask/answer.
5) Habitats lightly (match / say) using the same animals — do not invent a science lecture.
6) Adjective order — show the pattern with pictures; students build short noun phrases.
7) Appreciation — I like … They're so …
8) End with student production: ask/answer or short animal talk using can / can't.

Always: Model → guided practice → reduced support → independent student production.
Recycle the unit animals. Do not add new animals "for fun."

Watch for mix-ups:
- "Do you like …?" (feeling) is NOT the same as "Can it …?" (what it does)
- Short answers: it (one animal) vs they (more than one)
- can vs can't

════════════════════════════════════
C. PRIOR LEARNING (SUGGESTED — USE LIGHTLY)
════════════════════════════════════

Useful context only — do NOT assume mastery; do NOT teach as new Unit 8 grammar:
- Students may know farm/animal action talk from earlier levels (e.g. "It's running").
  If helpful, one quick bridge: It's running. → It can run. Then stay on can/can't.
- Do NOT teach "Can I help you?" as ability (that is offering help, not animal ability).
- Color/size words students already know can support adjective practice.

════════════════════════════════════
D. OPTIONAL ENRICHMENT (SUGGESTED — NOT REQUIRED)
════════════════════════════════════

Teachers may skip all of these and still complete the book.

1) Extra short-answer chain with unit animals only (it/they + can/can't).
2) One two-beat model: Do you like cheetahs? → Cheetahs can run. (feeling vs ability)
3) Warm-up with TWO adjectives only (big yellow parrot) before the full book order stack.
4) Only if action language is already easy: It's flying. → It can fly. (do not teach continuous as new grammar)

Do NOT add: past could/couldn't; permission can; long habitat essays; new animal lists.

════════════════════════════════════
E. GENERATION RULES
════════════════════════════════════

- Short student-facing sentences. No hard teaching jargon on slides.
- Visuals for every new animal and every sentence frame.
- One idea per slide. No duplicate "question then identical answer" filler.
- Prioritize practice, retrieval, and student production.
- Leave blank / open slides or pauses where the teacher can add their own activity.
- Success = students can say and ask about what animals can/can't do, build simple adjective+animal phrases, and say what they like — ready for the textbook pages.
