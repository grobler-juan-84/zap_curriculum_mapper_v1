# Project Decisions

**Status:** ACTIVE  
**Version:** 1.0  
**Purpose:** Record locked-in project decisions that emerged from internal brainstorming or explicit project choices. This file is the decision log; exploratory options belong in [`2-internal-brainstorming.md`](./2-internal-brainstorming.md).

---

## How to use this document

- Only record decisions that are intentionally locked for the project to follow.
- Prefer short, concrete statements over discussion.
- Link back to the brainstorming entry or prompt/step that produced the decision when possible.
- If a decision is later reversed, do **not** delete it — mark it superseded and add the replacement.
- Operational status (extraction progress, verification counts) stays in the dataset registry and project status docs; this file tracks **choices**, not progress.

### Decision template

```markdown
### D### — Short decision title

**Date locked:** YYYY-MM-DD  
**Status:** LOCKED | SUPERSEDED  
**Source:** brainstorming entry / prompt / discussion  
**Decision:**  
**Why:**  
**Implications:**  
**Supersedes:** — or D###
```
