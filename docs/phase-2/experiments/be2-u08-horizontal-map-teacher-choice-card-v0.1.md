## 6. Selected-pattern speaking scripts

Use: **final selected prior patterns** + **required Unit 8 language** + **Unit 8 animals**.  
Not every selected pattern must appear in every exchange.  
Do not claim these scripts appear in the publisher materials.

### Model (mapper-generated · PL-19 + PL-08)

A: Do you like cheetahs?  
B: Yes, I do. I like cheetahs.  
A: Me, too!

*(Optional current-unit add-on, not prior: `Cheetahs can run.`)*

### Exchange 2 (teacher draft · preference + reason)

A: What is it?  
B: It is a cheetah.  
A: Do you like cheetahs?  
B: Yes, I do. I like cheetahs because they can run fast.

**Patterns / provenance:**

- `What is it?` / `It is a cheetah.` — mapper-generated identification (not PL-22 exact)
- `Do you like…?` / `Yes, I do. I like…` — PL-19
- `because` — PL-16
- `can run fast` — current Unit 8 ability plus descriptive application
- Do **not** claim a verified prior `Why…?` pattern (PL-18 does not evidence `Why`)

### Exchange 3 (teacher draft · quantity + action + preference)

A: What are they?  
B: They are cheetahs.  
A: How many cheetahs are there?  
B: There are two cheetahs.  
A: What are they doing?  
B: They are running.  
A: Do you like cheetahs?  
B: Yes, I do. I like cheetahs.

**Patterns / provenance:**

- `What are they?` / `They are cheetahs.` — mapper-generated identification
- Quantity exchange — PL-03
- Present continuous exchange — PL-02 adapted to animal subjects
- `running` — current Unit 8 application
- Preference exchange — PL-19
