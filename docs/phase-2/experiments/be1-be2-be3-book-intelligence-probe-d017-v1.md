## 1. Purpose

1. Transfer the owner-approved BE2 v2 eight-column pattern to BE1-SB and BE3-SB.  
2. Check horizontal consistency of the approach.  
3. Probe whether the three overviews contain enough information for **future** vertical mapping.

**Safeguards:** previously taught ≠ mastered; shared topics ≠ progression; no invented links; missing evidence recorded rather than filled.

---

## 2. Horizontal consistency (BE1 / BE2 / BE3)

| Criterion | Finding |
|---|---|
| Eight-column structure | **Consistent** across all three books |
| Curriculum coverage (Phase 1–based) | **Strong** — all nine verified units represented in each book |
| Teacher readability / conciseness | **Adequate** for Book Intelligence density; teacher validation deferred to Chalkie workspace (not a Phase 2 blocker) |
| Learning Outcomes | **Usable** — all labeled AI-inferred; BE1 uniquely informed by extracted I Can item prompts; BE2/BE3 lack exact I Can text |
| Accuracy discipline | **Held** — no invented columns; empty/thin Phase 1 cells not fabricated |
| Books are not identical | **Correctly reflected** — themes, grammar families, and supporting strands differ by level |

### Meaningful horizontal differences (not defects)

| Difference | Notes |
|---|---|
| BE1 page ranges | Units start later in the printed book (U1 pp. 10–25) vs BE2/BE3 (U1 pp. 4–19) |
| BE1 I Can extraction | Checklist item prompts exist in Phase 1 activities; BE2/BE3 mostly note the block only |
| BE3 writing strand | Sentence/paragraph writing components are real but **outside** the eight columns |
| BE3 language thinness | Unit 8 has only 5 language rows — overview leans more on components/vocab |
| Mixed BE3 entity ID prefixes | Phase 1 legacy (D007 grandfathering); complicates cross-book ID matching, not overview usefulness |
| Publisher S&S | Used for BE2 v2 only; BE1/BE3 S&S unavailable locally this run — no coverage % claimed for BE1/BE3 |

### Recurring Phase 1 gaps (document only; no re-extraction)

1. **Exact I Can text** missing for BE2/BE3 (parked F017).  
2. **Checkpoint / review sections** outside units not represented (parked F018).  
3. **Cross-book entity-ID heterogeneity** (especially BE3) would hinder automated vertical joins later.  
4. Occasional **empty `full_text`** on language rows (BE3) forces reliance on labels/functions.

None of these blocked producing useful Book Intelligence overviews.

## 3. Vertical sufficiency probe (3–5 examples)

Question: **Do Phase 2 outputs contain enough evidence to identify meaningful learning progression across BE1 → BE2 → BE3?**

### Example A — Present continuous for current actions

| Level | Evidence in overview / Phase 1 |
|---|---|
| BE1 | U4 clothing *What are you/he wearing?*; U5 home *What are you/she doing?*; U9 yes/no *Is she…? / Are they…?* |
| BE2 | U1 classroom *What's she/they doing?* (core Language in Action) |
| BE3 | Not a primary spine target; present continuous appears mainly as clothing/weather support (U5) |

**Progression signal:** Introduction and heavy practice at BE1; recycled as a core system at BE2 U1; largely assumed / backgrounded by BE3.  
**Missing for fine mapping:** explicit “prior assumed” tags; activity difficulty measures.  
**Caution:** BE2 classroom PC is not simply “harder BE1 home PC” — topic shift matters.

### Example B — Animals, ability (*can*), habitats

| Level | Evidence |
|---|---|
| BE1 | U6 farm animals + present continuous actions; baby animals; care values — **not** modal *can* as core |
| BE2 | U8 wild animals + *can/can't* + habitats CLIL |
| BE3 | U4 animals + habitats vocab + *can/can't* + camouflage CLIL + manner adverbs; protect-habitats values |

**Progression signal:** Topic continuity with clear structural upgrade BE2→BE3; BE1 contributes animal lexicon/actions but not the same grammar system.  
**Missing:** formal prerequisite links; which BE2 habitat words are recycled vs new in BE3.

### Example C — Food preferences and quantity language

| Level | Evidence |
|---|---|
| BE1 | U7 party food; *What do/does … have?*; *don't/doesn't*; sweet/salty |
| BE2 | U7 food likes; *a/an/some*; offers |
| BE3 | U7 *some/any*; *much/many/a few/a little*; *How much/How many?*; vitamins |

**Progression signal:** Clear quantity-language expansion across books; likes/preferences recur with increasing grammar load.  
**Missing:** exact lexical overlap counts; workbook reinforcement (out of scope).

### Example D — Daily routines and telling time

| Level | Evidence |
|---|---|
| BE1 | Home/activity routines in present continuous (U5); days of week (U7) — **no** clock-time core unit |
| BE2 | U6 *o'clock* + *When do/does…? at…*; historical timekeeping CLIL |
| BE3 | U1 routines + finer clock times (*thirty, forty-five…*) + *before/after* + full frequency band (*always–never*) |

**Progression signal:** Time-telling introduced at BE2, extended at BE3; BE1 supplies related routine discourse without clock systems.  
**Missing:** whether BE3 expects BE2 o’clock mastery (overview cannot prove mastery).

### Example E — Jobs / work

| Level | Evidence |
|---|---|
| BE1 | No dedicated jobs unit |
| BE2 | U5 *What do you want to be?* + *because* + goods/services |
| BE3 | U2 *What does he do? / Where does he work?* + full present-simple job/workplace paradigm |

**Progression signal:** Introduction at BE2 (aspiration), extension at BE3 (current jobs/workplaces + richer present simple).  
**Missing:** no BE1 prior — vertical map must allow “starts at BE2” without forcing a BE1 node.

## 4. Sufficiency judgment

| Need for future vertical mapping | Current Phase 2 overviews |
|---|---|
| Spot thematic continuity across levels | **Sufficient** |
| Spot grammar-family introduction / recycling / extension (coarse) | **Mostly sufficient** for experimental probes |
| Prove mastery or teaching sequence inside a level | **Not sufficient** (and not claimed) |
| Automated entity-level vertical graph | **Not sufficient** (ID heterogeneity + missing I Can/checkpoints) |
| Lock a Phase 3 methodology/schema | **Not justified** |

### Recommendation

**Proceed with bounded Series Intelligence experiments using these overviews as horizontal baselines**, treating them as **minimum-sufficient** for coarse BE1→BE2→BE3 progression questions.

**Targeted improvements later (only if a vertical experiment stalls):**

1. Promote F017 selectively for BE2/BE3 I Can text if outcome-alignment becomes a blocker.  
2. Add optional cross-book “language-family tags” in Phase 2 notes (still non-schema) for the 3–5 probe strands.  
3. Do **not** expand extraction wholesale; do **not** start Phase 3 product work from this probe alone.

**Bottom line:** The simple eight-column approach **scales across three books** well enough to see real progression signals. It is **not** a nuclear reactor — and it does not need to be one yet.
