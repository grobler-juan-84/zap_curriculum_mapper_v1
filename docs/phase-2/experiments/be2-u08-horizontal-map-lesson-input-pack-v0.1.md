## 2. Product workflow being tested

```text
Complete eligible prior-language bank (Units 1–7)
        ↓
AI recommends 0–5 relevant frames (default, not a cap)
        ↓
Teacher accepts, deselects, replaces, adds, or selects none
        ↓
Selected frames become available lesson input
        ↓
Lesson generator combines them selectively with current-unit language
```


| Clarification          | Meaning                                                               |
| ---------------------- | --------------------------------------------------------------------- |
| 0–5 AI recommendations | Soft default only — **not** a teacher-selection cap                   |
| Complete bank          | Remains available for teacher browse / add                            |
| Final control          | Teacher decides                                                       |
| Lesson use             | Generator must **not** force every selected frame into every activity |


The first Arm A&B experiment tested only a **narrow polarity cue**. This pack records the fuller handover above as approved `[HM]` input for bounded Arm B2 **design**.

## 4. AI-recommended candidate set (≤5)

For the Unit 8 opener, recommend **four** prior frames that support a natural progressive conversation. Full bank: investigation PL-01…PL-22.


| PL ID     | Reusable frame                                                              | Source | Evidence               | Why recommended                                     | Caution / conditions                                                                    |
| --------- | --------------------------------------------------------------------------- | ------ | ---------------------- | --------------------------------------------------- | --------------------------------------------------------------------------------------- |
| **PL-19** | `Do you like + noun?` → `Yes, I do. I like…` / `No, I don't. I don't like…` | U7     | SS exact + SB verified | Core preference; enables both polarities            | Keep singular/plural honest; include **both** paths                                     |
| **PL-08** | `Me, too!` / `Me neither!`                                                  | U2     | SS exact + SB verified | Turns preference into short communicative exchanges | **Match polarity** — `Me neither!` only after don’t-like                                |
| **PL-01** | `What's he/she doing? He/She's + -ing.`                                     | U1     | SS exact + SB verified | Supports action description after ability talk      | Animal-subject forms (`What's the cheetah doing?`) are **mapper-generated adaptations** |
| **PL-03** | `How many + plural are there? There's / There are…`                         | U1, U6 | SS exact + SB verified | Natural with countable animal pictures              | Number must match the visual; optional — skip without a clear count scene               |


**Not recommended as prior language:** `Can …?` / `Yes, they can.` — **current Unit 8** ability (SS/SB Unit 8), even when useful next to prior preference/action frames.

**Not forced into this ≤5 set (still in complete bank):** PL-02, PL-13, PL-16, PL-18, PL-20, and others. Teachers may add them (§5). Prior owner choice recorded **nine** available IDs on the teacher-choice card — evidence that selection may exceed the AI default — but this narrower pack does **not** automatically force all nine as lesson input.

## 6. Progressive conversation demonstration

Illustrates the intended handover. **Not** a required script for every generated lesson. Not publisher text.

### Affirmative path (example)


| Line | Text                              | Provenance                                                                                     |
| ---- | --------------------------------- | ---------------------------------------------------------------------------------------------- |
| A    | What is it?                       | **Teacher-added** identification (selected; unverified / vertical — **not** PL-22 / not BE2 PL) |
| B    | It is a cheetah.                  | Mapper-generated + **current Unit 8** animal vocab                                             |
| A    | Do you like cheetahs?             | **Prior PL-19** + Unit 8 vocab                                                                 |
| B    | Yes, I do. I like cheetahs.       | **Prior PL-19**                                                                                |
| A    | Can cheetahs run?                 | **Current Unit 8** ability — not prior retrieval                                               |
| B    | Yes, they can. They can run fast. | **Current Unit 8** ability (+ descriptive enrichment; use *they*, not *the*)                   |
| A    | What is the cheetah doing?        | **Prior PL-01** (verified continuous frame) · animal wording = **mapper-generated adaptation** |
| B    | It is chasing the kangaroo.       | Mapper-generated application of PL-01 + Unit 8 vocab (*chase*, *kangaroo*)                     |


**Not in this pack’s final selected set:** optional agreement `Me, too!` (**PL-08**) — AI-recommended, teacher-deselected here. Remains in the complete bank for other teachers.

### Negative preference branch (compact alternative)


| Line | Text                              | Provenance                   |
| ---- | --------------------------------- | ---------------------------- |
| A    | Do you like snakes?               | **PL-19** + Unit 8 vocab     |
| B    | No, I don't. I don't like snakes. | **PL-19**                    |
| A    | Me neither!                       | **PL-08** (correct polarity) — **illustrative only**; PL-08 not selected for this pack |


Do **not** follow `Yes, I do. I like…` with `Me neither!`.

**Cautions:**

- Use “Yes, **they** can,” not “Yes, the can.”
- `What is it? / It is a cheetah` = teacher-added / mapper-generated unless later exact prior evidence is established (vertical mapping).
- Ability Q&A = current Unit 8, not prior retrieval.
- Entire conversation need not appear in every generated lesson; selections are available inputs.
- Optional quantity beat with **PL-03** (e.g. after plural ID) remains available but is not forced into this demo.

## 7. Lesson-generator handover rules

The drafted Arm B2 prompt (design pending owner approval; **generation** not yet authorized) should:

1. Receive **only** teacher-approved selected frames **plus** current-unit obligations.
2. Use selections **where natural**.
3. Preserve both **positive and negative** preference paths.
4. Build **short progressive exchanges**, not only isolated drills.
5. Encourage increasingly **independent** student production.
6. Label generated examples `[SUPPLEMENTARY]`.
7. **Avoid** forcing all selected frames into every activity.
8. **Avoid** unsupported vocabulary, advanced grammar, or future-unit content.
9. Keep `[SS]` / `[SB]` / `[WB]` / `[HM]` / `[SUPPLEMENTARY]` distinguishable.
