## Core — preference + agreement (use this first)

**Affirmative path** · prior **PL-19** + **PL-08** · Unit 8 animal vocab

```text
Do you like cheetahs?
Yes, I do. I like cheetahs.
Me, too!
```

**Negative path** · prior **PL-19** + **PL-08** · Unit 8 animal vocab

```text
Do you like snakes?
No, I don't. I don't like snakes.
Me neither!
```

**Polarity rule (do not mix):**


| After this answer…           | Use this agreement |
| ---------------------------- | ------------------ |
| `Yes, I do. I like…`         | `Me, too!`         |
| `No, I don't. I don't like…` | `Me neither!`      |


Swap any Unit 8 animal (cheetah, snake, zebra, …) to match the picture.

## Optional add-ons (only if the picture supports them)



### Quantity · Script B · prior **PL-03**

```text
What are they?
They are zebras.
How many zebras are there?
There are three zebras.
```

- Number must match the real picture.  
- `What are they?` / `They are…` = **mapper-generated** identification (not exact publisher ID wording).



### Action + ability · Script C · prior **PL-01** (adapted) + **current Unit 8 ability**

```text
What is the cheetah doing?
It is running.
Can cheetahs run?
Yes, they can.
```

- `What is the cheetah doing?` / `It is running.` = **mapper-generated** adaptation of PL-01.  
- `Can cheetahs run?` / `Yes, they can.` = **current Unit 8** ability — **not** prior retrieval.
