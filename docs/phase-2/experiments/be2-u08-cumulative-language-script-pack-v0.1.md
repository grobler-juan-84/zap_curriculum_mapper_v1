## 1. Purpose and boundaries

This pack tests whether **teacher-selected prior language** can enrich Big English 2 Unit 8 opener communication without curriculum drift.

| Principle | Statement |
|---|---|
| Scripts | Mapper-generated applications for teacher use |
| Not publisher text | These exchanges are **not** claimed as textbook scripts |
| Mastery | Prior exposure does **not** prove mastery |
| Availability | No structure must appear merely because it was selected |
| Current unit | Unit 8 ability (`can` / `Cheetahs can run.`) remains current-unit language, not prior retrieval |

> Selecting a pattern makes it available for the Unit 8 lesson. It does not require every selected pattern to appear in every speaking script or activity.

**Out of scope:** habitats, phonics, culture, values lesson, adjective-order grammar pages, Chalkie generation, D018 changes, UI/schema.

## 3. Script design principles

1. Short, natural exchanges  
2. Full-sentence student responses where the pattern supports them  
3. Gradual increase in language production (model → guided → slightly freer)  
4. Purposeful repetition of high-value patterns  
5. No unnecessary vocabulary beyond Unit 8 animals + supported actions  
6. No forced Wh- questions  
7. No invented publisher content  
8. No unrelated Unit 8 expansion (habitats, culture, phonics, etc.)

---

## 4. Four concise script sequences

### Script A — Identification and preference

| Field | Content |
|---|---|
| **Purpose** | Move from naming one animal to preference + agreement |
| **Visual** | One clear animal picture (e.g. a cheetah) |
| **Teacher model (affirmative)** | A: What is it? → B: It is a cheetah. → A: Do you like cheetahs? → B: Yes, I do. I like cheetahs. → A: Me, too! |
| **Teacher model (negative)** | A: What is it? → B: It is a snake. → A: Do you like snakes? → B: No, I don't. I don't like snakes. → A: Me neither! |
| **Guided exchange** | Teacher asks `What is it?` and `Do you like…?`; students answer with the polarity that matches their opinion; peers use **matching** agreement (`Me, too!` after yes/like; `Me neither!` after no/don’t like) |
| **Slightly independent** | Pair with a different animal card; same pattern chain with both polarities available |
| **Patterns used** | Mapper-generated ID · **PL-19** (yes **and** no paths) · **PL-08** (polarity-matched) |
| **Provenance** | `What is it?` / `It is a…` = mapper-generated (not PL-22 exact). Preference = PL-19. Agreement = PL-08. |
| **Optional simplification** | Drop agreement; keep both `Yes, I do. I like…` and `No, I don't. I don't like…` |

---

### Script B — Quantity and plural language

| Field | Content |
|---|---|
| **Purpose** | Practise plural naming + counting, then light preference |
| **Visual** | Picture with a clear countable set (example below uses **three** zebras — change the number to match the real image) |
| **Teacher model** | A: What are they? → B: They are zebras. → A: How many zebras are there? → B: There are three zebras. → A: Do you like zebras? → B: Yes, I do. |
| **Guided exchange** | Teacher controls count question; students answer from the picture only |
| **Slightly independent** | New picture; students ask `How many…?` in pairs |
| **Patterns used** | Mapper-generated plural ID · **PL-03** · **PL-19** (natural close) |
| **Provenance** | `What are they?` = mapper-generated. Quantity = PL-03. Preference = PL-19. Number is illustrative / visual-dependent. |
| **Optional simplification** | Omit preference; keep ID + count only |

---

### Script C — Action and ability

| Field | Content |
|---|---|
| **Purpose** | Link observed action to current-unit ability; optionally add a reason |
| **Visual** | Cheetah (or animal) shown running / in motion |
| **Teacher model** | A: What is the cheetah doing? → B: It is running. → A: Can cheetahs run? → B: Yes, they can. → A/B: I like cheetahs because they can run fast. |
| **Guided exchange** | Teacher models continuous + ability; students repeat; stronger students add `because` line |
| **Slightly independent** | Swap animal/action supported by Unit 8 evidence (e.g. kangaroo + jump) if the visual supports it |
| **Patterns used** | **PL-01** (adapted) · current Unit 8 ability · **PL-16** (optional final line) |
| **Provenance** | `What is the cheetah doing?` / `It is running.` = mapper-generated adaptation of PL-01. `Can cheetahs run?` / `Yes, they can.` = **current Unit 8** (not prior). `because` = PL-16. |
| **Optional simplification** | Stop after ability Q&A; omit the `because` line |

**Do not** imply that `Can cheetahs run?` was taught before Unit 8.

---

### Script D — Picture-scene choice

| Field | Content |
|---|---|
| **Purpose** | Scene-dependent existence check + third-person preference |
| **Visual** | Mixed animal scene that clearly includes (or excludes) a zebra; a visible “she” (classmate / character) for PL-20 |
| **Teacher model** | A: Is there a zebra? → B: Yes, there is. → A: Does she like zebras? → B: Yes, she does. |
| **Guided exchange** | Teacher points to scene and classmate/character; short Yes/No with full short answers |
| **Slightly independent** | Students ask `Is there a …?` about another Unit 8 animal in the same scene |
| **Patterns used** | **PL-13** · **PL-20** |
| **Provenance** | Existence = PL-13 (mapper-generated animal application). Third-person preference = PL-20. |
| **Optional simplification / omit rule** | **Omit Script D entirely** when no suitable scene exists. Do not force PL-13. |

## 6. Comparison baseline

Isolated Unit 8 textbook frame (required current-language baseline — not “wrong”):

```text
Do you like cheetahs?
Yes, I do!
Cheetahs can run.
```

The cumulative pack **supplements** this baseline; it does not replace Unit 8 obligations.

## 7. Qualitative comparison

| Lens | Isolated U8 frame | Manual cumulative pack |
|---|---|---|
| Meaningful student language | Thin but clear | Longer purposeful chains when visuals support them |
| Reuse of verified prior learning | Preference half echoes U7 implicitly; little deliberate reuse | Explicit PL-19 / PL-08 / PL-03 / PL-01 / PL-16 / PL-13 / PL-20 |
| Q&A variety | One preference + ability statement | Identification, quantity, action, ability, agreement, existence, 3rd-person like |
| Full-sentence production | Short | Encourages fuller answers (`I like…`, `There are…`, `It is running.`) |
| Naturalness | Very natural and simple | Natural if scripts stay short and scene-true |
| Cognitive load | Low | Higher if all nine treated as mandatory; manageable if **available ≠ used** |
| Curriculum fidelity | Strict textbook minimum | High if ability stays labeled current-unit and habitats/etc. stay out |
| Risk of unnecessary complexity | Low | Medium if Wh-forcing, invented vocab, or packing all patterns into one activity |
| Teacher flexibility | Limited path | High — choose Script A–D / omit D / simplify lines |
| Classroom usability | Immediate | Usable as card-sized sequences with picture support |

**Verdict:** For opener practice with pictures, the cumulative pack offers **more meaningful communicative practice** than the isolated frame alone, provided teachers treat the nine IDs as an **available bank**, run only the sequences the visual supports, and keep **both preference polarities** (like / don’t like) with polarity-matched agreement.

**Owner feedback (teacher-choice card §7, Q4–5):** Confirms that isolated page frames feel too restrictive when some students like an animal and others do not. Extra available frames improve freedom of movement. Main unnatural risk is practising only the positive path, or mismatching `Me, too!` / `Me neither!` to polarity.

## 8. Findings

1. **Do cumulative scripts offer more meaningful communication?**  
   **Yes** — at document-review level and per owner feedback. Scripts A–C extend preference into agreement, counting, action, and reasoned likes while keeping Unit 8 ability correctly labeled. Owner emphasis: both **yes** and **no** preference paths are needed for natural classroom talk.

2. **Which prior patterns add the most value?**  
   **PL-19** (core, including negative answers), then **PL-08** when polarity-matched, and **PL-03**. **PL-01** (adapted) pairs cleanly with current-unit ability in Script C. **PL-16** remains optional enrichment.

3. **Which patterns are optional, weak, or scene-dependent?**  
   **PL-13** and **PL-20** are scene-dependent (Script D). **PL-02** is optional when singular action suffices. **PL-18** is a family/reference layer, not a forced script driver. **PL-08** is valuable but **misfires** if used with the wrong polarity.

4. **Does treating nine patterns as mandatory create overload?**  
   **Yes.** Nine-as-mandatory would crowd a short opener lesson.

5. **Does “available vs used” solve that?**  
   **Yes.** This pack uses seven as primary/optional script drivers and leaves PL-02 and PL-18 unused without loss of quality. Owner feedback further supports availability: more frames for choice, not one forced path.

6. **Are the scripts simple enough to continue horizontal mapping?**  
   **Yes.** Scripts A–C (with dual-polarity preference) justify continuing; Script D remains optional.
