## B. Whole-book snapshot

Big English 2 SB presents nine thematic units with a stable instructional spine: **target vocabulary → song/story → Language in Action / Grammar → CLIL → Culture → Values → Phonics → Review (+ I Can)**.

Across the book, students practice **everyday communication** around classroom life, leisure, home, town, jobs, daily routines, food, animals, and the calendar/year. Core grammar moves from **present continuous and imperatives**, through **likes, location/possession, exists/wants/prices**, to **present simple routines, food quantifiers, modal *can*, and frequency/weather**.

This overview summarizes **what the book teaches unit by unit**. It does **not** claim mastery, prior learning from BE1, or progression into BE3.
