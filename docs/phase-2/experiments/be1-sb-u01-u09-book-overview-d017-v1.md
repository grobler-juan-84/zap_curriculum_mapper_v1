## B. Whole-book snapshot

Big English 1 SB presents nine beginner thematic units with the familiar Big English spine: **vocabulary → song/story → Language in Action / Grammar → CLIL → Culture → Values → Phonics → Review (+ I Can)**. Units also include short **projects**.

Core language stays concrete and classroom-near: objects, family, body, clothes, home actions, farm animals, party food, toys, and play. Grammar centers on **identification (*What is it? / What are they?*)**, **have**, **imperatives**, early **present continuous**, **possessives**, **there is/are**, and **like / don’t like**.

This overview summarizes **what the book teaches unit by unit**. It does **not** claim mastery or progression into BE2/BE3.
