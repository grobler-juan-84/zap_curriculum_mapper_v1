## 2. Genuine usefulness vs extra detail

### Genuine improvements in B

1. **Implicit *at* (FS-03).** A mentioned *at* as something students need; B’s “implicit / easy to under-teach” is a real pedagogical nudge grounded in how the book presents answers without a titled grammar box.  
2. **Separation of clock talk vs routine talk (STR-01 vs STR-02).** A said they were different; B makes that the organizing spine of the lesson recommendations.  
3. **CON-02 (*-s* recycles in U8).** Adds a forward-looking awareness teachers can use in one sentence—without inventing prerequisites.

### Extra detail / complexity (not automatically valuable)

1. **ID density** (STR-01…, FS-01…, CON-01…) helps project traceability more than a busy teacher’s prep sheet.  
2. **CON-01** largely restates “Wh- questions use a helper before the subject”—a competent teacher may already infer that from A.  
3. Vocabulary section in B adds little beyond A; Phase 2 did not meaningfully enrich the word list for this focus.

**Verdict on usefulness:** B is **modestly more useful** for planning the *When do/does* focus—mainly by naming implicit *at* and sharpening structure separation—not because it dumps more curriculum data. If B had included all eight V1.2 connections, usefulness would likely have dropped (noise).

## 5. Overall experimental conclusion (not a methodology lock)

For this **single** teaching focus on BE2 U6, curriculum-informed Brief B is **slightly better for classroom planning** than Phase 1–only Brief A, chiefly by:

- making **implicit *at*** visible, and  
- keeping **clock questions vs routine questions** cleanly separated, plus  
- one **relevant** cross-unit note on third-person *-s* (CON-02).

It is **not** dramatically better. Gains are easy to lose if Phase 2 output is pasted in bulk (IDs, all connections, all strands).

**Do not** treat this as validation of Phase 2 V3.1 or Cross-Unit V1.2 as a production methodology. **Do not** declare Phase 3 started.

---

## 6. Recommendation for the next experiment

1. **Teacher micro-test (preferred):** Show A and B (or a cleaned B without project IDs) to 1–2 teachers; ask which they would use for tomorrow’s lesson and why—measure usefulness directly.  
2. **Or** repeat this A/B design on a different focus (e.g. U8 *can/can’t* or adjective order) to see if the “modest gain” pattern holds.  
3. **Avoid** whole-book Phase 2 processing until a teacher-facing usefulness signal is clearer than this single desk evaluation.

Optional cleanup for any future “teacher pack” derived from B: strip STR/FS/CON codes from the face of the brief; keep them in footnotes for the project.
