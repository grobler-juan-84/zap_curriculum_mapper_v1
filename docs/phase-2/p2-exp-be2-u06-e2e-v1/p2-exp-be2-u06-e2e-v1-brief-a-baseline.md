## Main language target

Unit 6 centres on talking about **when people do everyday things**.

Core frames on the Language in Action pages (`bep2_lang_u6_002`, `bep2_lang_u6_003`, component `bep2_comp_u6_04`):

- *When does he/she + verb?* → *He/She [verb-s] at [time].*  
  Example: *When does he get up? He gets up at 6:00.*
- *When do you + verb?* → *I [verb] at [time].*  
  Example: *When do you go to bed? I go to bed at 8:00.*

Closely related schedule language (`bep2_lang_u6_004`): *When does the movie start? It starts at 8:00.* (start / finish).

Earlier in the unit, clock language is taught (`bep2_lang_u6_001`): *What time is it? It’s … o’clock.* That supports the time answers but is a separate frame from the *When do/does* routine questions. Later, a grammar page reviews Wh- question words (`bep2_lang_u6_005`), and a review game recycles routine statements (`bep2_lang_u6_006`).

Students practise these through listen/build sentences, write *do/does*, sticker ask-and-answer, and pair work (e.g. Acts 9–13).

## Relevant vocabulary

**Clock times (listed targets, p. 90):** *one o’clock* … *twelve o’clock* (`bep2_vocab_u6_001`–`012`).

## Foundational knowledge evident from the source

From the textbook language rows and activities alone:

- Students need to **read/say hourly clock times** and use *It’s … o’clock* before they can answer *at + time* confidently (pp. 90–91; Acts 1–6).
- Answers use **present simple** with a clear **third-person -s** pattern in the book examples (*gets up*, *starts*).
- Guided writing asks students to choose ***do* vs *does*** (Act 10), so the book itself treats that choice as a practice point.
- Time answers use the preposition ***at*** with clock times in every core example above.

Publisher “I Can” wording on the review page is **not extracted** as language entities—only a page note that an I Can block exists (`bep2_p105`). Exact self-assessment sentences are therefore unavailable from Phase 1.

## Possible student difficulties (teaching considerations — not textbook facts)

These are classroom considerations inferred from the patterns in the book, not claims that the book labels them as hard:

1. Mixing *What time is it?* with *When do/does…?* (different question shapes, both use clock times).
2. Choosing *do* vs *does*, and remembering third-person *-s* in answers.
3. Inserting *at* before the time (*gets up 6:00* vs *gets up at 6:00*).
4. Digital-looking times in examples (*6:00*) versus *o’clock* wording on the opener pages.

Audio-dependent activities (e.g. Track 122 for Act 5; Track 133 for Act 29) may limit independent checking without the tracks (`bep2_issue_0010`, `bep2_issue_0011`).

## Practical teaching considerations

1. Keep the **communicative goal** visible: ask when someone does a routine and answer with *at + time*.
2. Warm up with **o’clock** recognition so *at + time* answers have something to attach to.
3. Use Act 9–12 style work: model *When does…?* / *When do you…?*, then pair ask-and-answer with visuals/stickers.
4. Spend a short, explicit moment on ***do/does*** and third-person *-s* while students write (Act 10), because the book asks for that choice.
5. Treat CLIL (old clocks), culture days, values (*Be on time.*), and *ch/tch/sh* phonics as **supporting strands**—useful, but not the main goal of this focus lesson set.
6. End-of-unit review/game language can recycle routines; do not assume mastery from exposure alone.
