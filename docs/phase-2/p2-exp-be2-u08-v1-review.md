## 2. Executive unit interpretation

**Teacher-readable summary (`AI_INTERPRETATION`, grounded below):**

Unit 8 teaches children to **name wild animals**, talk about **what animals can and cannot do** (*Can …? Yes, it/they can. / No, it/they can't.*), **order adjectives** before nouns (opinion → size/shape → age → color), and **express appreciation** (*They're so + adjective*). Supporting strands: **animal habitats** (CLIL), **animals near children’s homes** (culture), **Appreciate animals** (values), and **ou / ow** phonics.

This is not a clock/routine unit (U6) or food preference/offer unit (U7). The communicative core is **ability + multi-adjective description + appreciation**, with habitats as a major supporting science strand.

## 4. Grammar and communicative-function analysis

### 4.1 Modal *can / can't* (ability)

| Field | Content | Tag |
|---|---|---|
| Structure | Affirmative *X can V*; Q *Can a/an X V?* / *Can Xs V?*; short answers *Yes, it/they can.* / *No, it/they can't.* | `BOOK_EVIDENCE` langs 001–003 |
| Function | stating / asking about animal abilities | `BOOK_EVIDENCE` |
| Examples | *Cheetahs can run.* / *Can a kangaroo jump? Yes, it can.* / *Can snakes run? No, they can't.* | `BOOK_EVIDENCE` |
| Progression | **Recognition:** song/story Acts 4–8. **Guided:** Acts 9–11. **Production opportunity:** Acts 12–13, 17, 35 | `AI_INTERPRETATION` |
| Difficulty | *it* vs *they*; *can't* spelling/contraction; confusing ability *can* with permission *can* (not taught here) | `AI_PREDICTED_DIFFICULTY` |

### 7.2 Plausible Korean EFL — `AI_PREDICTED_DIFFICULTY` (hypotheses only)

| Hypothesis | Linguistic reason | LRs |
|---|---|---|
| Modal *can* for ability may be over-/under-extended to permission | English *can* is polysemous; Korean ability/permission forms differ | LR-02–LR-05 |
| Fixed adjective order is opaque | Korean prenominal modifiers do not follow the same opinion-size-age-color template | LR-06 |
| *They're so + adj* intensifier pattern may be underused | Intensifier constructions differ cross-linguistically | LR-07 |
| *ou* vs *ow* for similar vowel sounds | Multiple English spellings | LR-12 |

## 13. Lessons learned and recommendations

1. Repeating the U7 method on U8 worked without redesign.  
2. Unit-native grammar systems must drive LRs (ability/adj order here).  
3. Recycled preference language should stay supporting when not the unit’s main `language[]` focus.  
4. I Can extraction gap is a recurring evidence limitation across 6/7/8.  
5. Still **do not** lock a Phase 2 schema after three BE2 units without owner decision.  
6. Suggested next owner choices: accept D016 set complete for LR method; teacher-validation pilot; or extend to another book/level — **not auto-started**.
