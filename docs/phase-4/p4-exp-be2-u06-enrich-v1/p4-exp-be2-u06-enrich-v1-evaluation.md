Evaluate **decisions** (what / whether / priority / smallest action), not explanation quality.

### Verdict on decisions

For this teaching focus, Phase 2 V3.1 + selected V1.2 **did not change the three enrichment decisions**. Proposal B recommends the same interventions, same priority classes, and the same smallest teacher actions as Proposal A.

What changed is mostly **explanation precision** (especially calling *at* implicit / easy to under-teach) plus one **optional** CON-02 awareness sentence. That micro-add is not enough to claim that curriculum intelligence produced a different enrichment plan.

Per protocol: longer or more precise explanation ≠ decision improvement.

## 3. Genuine usefulness vs extra detail

### Genuine (small)

1. **FS-03 implicit** — sharpens *why* a teacher might stress *at* without inventing a new action.  
2. **CON-02 one-liner** — only cross-unit decision A could not make; still optional and skippable.  
3. **Declining CON-01 as enrichment** — useful restraint; avoids padding.

### Extra detail (not decision value)

1. STR/FS ID density for classroom reading.  
2. Restating A’s three ideas with interpretive labels.  
3. “Frequent reinforcement candidate” flags without class evidence—must not escalate priority to essential.

## 5. Overall experimental conclusion (not a methodology lock)

**Central answer:** For BE2 U6’s *When do/does…?* focus, Phase 2 V3.1 + selected V1.2 did **not** identify better enrichment *decisions* than Phase 1 alone. They produced a **modestly clearer rationale** for the same optional interventions, plus one tiny optional cross-unit awareness note.

This aligns with the prior e2e teacher-brief finding (modest planning usefulness, easy to lose to ID noise)—and is stricter on enrichment: **same three moves**.

**Do not** treat this as validation of Phase 2 / V1.2 / Phase 4 methodology. **Do not** declare Phase 3 or Phase 4 formally started.

---

## 6. Recommendation for next steps

1. Prefer a **teacher micro-test** of the three conditional moves (with or without IDs stripped) over more desk A/B writeups on this same unit/focus.  
2. If repeating the enrichment A/B design, choose a focus where Phase 1 is thinner (so decision change is more possible)—not another unit where the book already stages Act-style practice for the focus.  
3. Avoid whole-book Phase 2 scale until a stronger signal appears that interpretation changes **what teachers would actually add**, not only how well the brief explains it.
