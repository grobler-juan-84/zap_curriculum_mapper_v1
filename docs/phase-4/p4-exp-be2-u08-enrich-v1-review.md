## 3. Enrichment opportunities (4)

Fewer and stronger. Each is **optional** — teachers can skip all and still teach the book.

### E1 — Short-answer confidence: *it/they* + *can/can't*

| Field | Content | Tag |
|---|---|---|
| Textbook target | LR-03 / LR-04 ability Q&A | `BOOK_EVIDENCE` |
| Possible difficulty | Wrong pronoun or polarity in short answers | `AI_PREDICTED_DIFFICULTY` |
| Suggested enrichment | 2–3 minute oral chain with **unit animals only**: *Can a kangaroo jump? → Yes, it can.* / *Can snakes run? → No, they can't.* Same frames as the book; more turns, same words | `AI_INTERPRETATION` |
| Why it might help | Strengthens foundational structure without new grammar or vocab | `AI_INTERPRETATION` |

### E2 — Keep *like* and *can* on separate rails

| Field | Content | Tag |
|---|---|---|
| Textbook target | Preference opener (LR-13) then ability (LR-02) | `BOOK_EVIDENCE` |
| Possible difficulty | Students blur *Do you like cheetahs?* with *Can cheetahs run?* | `AI_PREDICTED_DIFFICULTY` |
| Suggested enrichment | One clear two-beat model card (same pair of animals): (1) *Do you like …?* (2) *Cheetahs can run.* Teacher points to “feeling” vs “what it does” | `AI_INTERPRETATION` |
| Why it might help | Prevents function mix-up at the unit’s hardest conceptual fork; no new structures | `AI_INTERPRETATION` |

### E3 — Two-adjective step before the full stack

| Field | Content | Tag |
|---|---|---|
| Textbook target | LR-06 adjective order | `BOOK_EVIDENCE` |
| Possible difficulty | Four-slot order is heavy for beginners | `AI_PREDICTED_DIFFICULTY` |
| Suggested enrichment | Brief warm-up: build **two** adjectives only (*big yellow parrot*, *funny young monkey*) using book animal nouns + known size/color words, then open the book’s fuller order page | `AI_INTERPRETATION` |
| Why it might help | Floor-first scaffolding; not advanced grammar — less load before the textbook rule | `AI_INTERPRETATION` |

### E4 — Optional bridge: action → ability (same verbs)

| Field | Content | Tag |
|---|---|---|
| Textbook target | Ability with action verbs already in song/story (*run, jump, swim, fly*, …) | `BOOK_EVIDENCE` of verbs in continuous text / ability frames |
| Vertical note | BE1 farm continuous (*What's it doing? It's running.*) is a **teaching opportunity**, not a prerequisite | Phase 3 / `AI_INTERPRETATION` |
| Suggested enrichment | Optional pair of picture prompts: *It's running.* → *It can run.* / *It's flying.* → *It can fly.* Use only if the class already knows those action words; **do not** teach continuous as new U8 grammar | `AI_INTERPRETATION` |
| Why it might help | Familiar meaning supports new *can* frame; builds confidence. Skip if continuous is shaky | `AI_INTERPRETATION` |

**Deliberately left blank:** phonics *ou/ow*; habitat poster redesign; culture chart; BE3 *but can't* / BE4 *could* (too soon / harder content); permission *can*.
